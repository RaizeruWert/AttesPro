# АттестПро

Веб-приложение для предварительной подготовки педагогических и руководящих работников к аттестации в ПМР.

## Ключевая особенность: несколько должностей у одного человека

Пользователь создаёт **один аккаунт и один профиль**, а затем добавляет отдельные записи о каждой должности / педагогической нагрузке. Например:

- Заместитель директора — тип «Руководящая», предмет не указывается.
- Учитель — тип «Педагогическая», предмет «Молдавский язык».

Заявка на аттестацию всегда привязана к конкретной записи `Assignment`. Поэтому материалы заместителя директора и материалы учителя молдавского языка не смешиваются. Если у человека три должности, он может создать три независимых пакета.

## Возможности

- регистрация, вход, выход, личный профиль;
- несколько должностей, предметов и организаций на одном аккаунте;
- отдельные заявки на подготовку по каждой должности;
- анкета и сохранение ответов;
- загрузка документов (PDF, DOC/DOCX, XLS/XLSX, ODT, JPG/PNG; до 15 МБ на файл);
- контроль комплектности по настраиваемому списку;
- защищённое скачивание загруженных файлов;
- сборка ZIP-архива с документами и сопроводительной информацией;
- админ-панель для настройки перечня документов;
- тест на сценарий «заместитель директора + учитель молдавского языка».

## Запуск на компьютере

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python manage.py makemigrations core
python manage.py migrate
python manage.py seed_checklist
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000

## Публикация на Render

1. Создайте репозиторий GitHub и загрузите содержимое папки проекта.
2. На Render создайте Web Service из репозитория.
3. Build Command:
   `pip install -r requirements.txt && python manage.py makemigrations core && python manage.py migrate && python manage.py seed_checklist && python manage.py collectstatic --noinput`
4. Start Command:
   `gunicorn config.wsgi:application`
5. Добавьте переменные окружения:
   - `SECRET_KEY` — длинный случайный секрет;
   - `DEBUG=0`;
   - `ALLOWED_HOSTS=.onrender.com`;
   - `SECURE_SSL_REDIRECT=1`.
6. Для сохранения загруженных документов подключите Persistent Disk и задайте `MEDIA_ROOT=/var/data/media`, mount path `/var/data`.
7. Для постоянного хранения данных подключите PostgreSQL и используйте `DATABASE_URL` из Render.

**Важно:** бесплатная файловая система веб-сервиса может быть временной. Без постоянного диска загруженные документы могут исчезнуть при повторном развёртывании. Для реальной эксплуатации необходимы резервное копирование, HTTPS и отдельная политика хранения персональных данных.

## Администрирование

Создайте суперпользователя командой `python manage.py createsuperuser`, затем откройте `/admin/`. В разделе «Checklist items» можно изменить названия, область применения и обязательность пунктов. Начальный список — демонстрационная настройка, а не юридически исчерпывающий перечень.

## Законодательная основа и ограничения

При разработке учтён профильный нормативный акт ПМР: Приказ Министерства просвещения ПМР от 07.02.2022 № 107, которым утверждено Положение о порядке аттестации руководящих и педагогических работников, с изменениями. Перед реальным использованием нужно сверить актуальную редакцию, применимую к конкретной должности, типу организации и цели аттестации. Перечень документов в приложении является настраиваемым и не заявляется как официальный обязательный перечень.
